**Planned compiler gate:** The accepted plan and [issue #19](https://github.com/clockgrove/factory-rebuild/issues/19) call for pinned-source read-only preview, deterministic graph checks, one independent source-backed review, at most one evidenced revision and re-review, and a specific human fallback only for unresolved defects or authority. Early human graph inspection is calibration, not the intended routine approval path. None of this preview/reviewer path is implemented in the current package.

**Planned diagnostics:** [Issue #28](https://github.com/clockgrove/factory-rebuild/issues/28) tracks agent-readable status and correlated local structured diagnostics. The atomic snapshot remains continuation truth; diagnostic logs cannot drive replay or recovery, and OpenTelemetry is an optional later exporter. The current package has a one-line CLI status and private per-worker output files, but no correlated diagnostic timeline, read/follow surface, or OTel instrumentation.

**Next action:** close the accepted pre-pilot trunk gaps in issues [#19–#25 and #28](https://github.com/clockgrove/factory-rebuild/issues), then publish an exact public artifact and run the private W0-001/LFS Clockgrove pilot through only its documented third-party interface ([#26](https://github.com/clockgrove/factory-rebuild/issues/26)). Factory source must never be its own target. The public fixture files and Objective templates are sufficient to reproduce generic Factory acceptance in a repository the contributor controls.
