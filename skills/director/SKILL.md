# Factory director

Resolve the target repository and Objective issue number from the request. Refuse any Factory source, rebuild, or archive repository as a target. Read the target repository's own instructions and Objective; they remain the authority for scope and validation. Use `factory help` for the installed CLI surface. Keep controller scheduling inside Factory rather than reproducing it in chat or editing its state.

For an install-only request, use the packaged `setup` skill and stop before execution. For planning, use `factory plan --objective N --output ABSOLUTE_PRIVATE_FILE`; show its pinned source packet, graph, review status, and any unresolved question. A question requires a named operator's specific answer or refusal, actor, and reason before `factory decide` records the decision. Do not call an unresolved plan runnable. For execution, confirm the installed repository binding and authority, then use `factory run --objective N --plan FILE` with a clean decided candidate. Without a plan file, `run` compiles and independently reviews a fresh graph.

Use `factory status --objective N` to report progress, failure, final validation, or a selection pause. If an Objective pauses for media, read candidate IDs and digests from status; use `factory review --objective N --item ID --set SET_ID --output ABSOLUTE_NEW_DIRECTORY` for human review outside the target checkout. Obtain the human's whole-set selection, use `factory select --objective N --item ID --set SET_ID` with an optional reason and explicit `--bind` for each pending direct dependent that may consume the set, then run again. Respect target-owned Git LFS rules and never substitute unselected files. Structured source bindings can name pinned repository files, Objective-cited absolute private files, or recognized GitHub Objective attachments; never invent access, source identity, rights, or tool provenance. Use `factory cancel --objective N` for an authorized stop and `factory retry --objective N --item ID` only for an explicitly authorized new attempt. Report the resulting status or refusal and return; do not poll indefinitely. Managed-agent and sandbox execution remain unavailable.
